relay-knowledge 1.1.18 发布说明

1.1.18 增加 Maven reactor 依赖证据和下游影响查询，改进代码调用检索与索引诊断， 并加强 Windows SQLite 默认存储目录和校验。

发布日期：2026 年 9 月 18 日。

发布与下载 crates.io Checksums

安装与验证

cargo install relay-knowledge --version 1.1.18 --locked
relay-knowledge version --format json
relay-knowledge map validate --type all --format json
relay-knowledge service doctor --format json

Release 提供六个平台二进制压缩包。安装前用 checksums.txt 校验所选压缩包；独立的 CLI skill 包与二进制在同一个 GitHub Release 发布。

本版变化

  • Maven reactor 模块与关系成为按快照保存的事实，依赖和下游影响视图支持分页。
  • 配置读取、跨语言类型调用、Java 类成员调用及未解析的 C 函数指针调用具有更完整的图谱证据。
  • 索引诊断提供有界预览、明确的截断和内容完整性状态，并暴露源码 I/O 失败，不掩盖 stale 或 degraded scope。
  • 冷索引减少配置扫描工作与全文检索参数的临时复制，仍保留持久检查点和检索文档。
  • Windows 新安装使用受保护 ACL 的账户 SID SQLite 数据目录；升级时继续选择已有 LocalAppData 存储。

升级与回滚

软件投影 schema 9 会使已有 Maven 投影进入 stale 状态，直到持久修复或重新索引完成。 查询 reactor 模块或下游影响前，应等待任务完成。升级前备份 runtime database 和全部分片。 降级前停止服务、等待或取消活动任务，再恢复一致的升级前数据库备份；不要手工修改 reactor marker 或 checkpoint。

Windows 新安装需预先配置 D:\relay-knowledge\users\<user-sid>\data 下的账户 SID 目录，或将 RELAY_KNOWLEDGE_DATA_DIR 指向绝对且可写的目录。 已有数据不会自动搬迁。替换常驻服务二进制前，先执行服务生命周期 dry-run 和 service doctor。Repository Map v4 仍要求 1.1.17 或更新的 reader； 使用更旧版本前，先从 Git 或备份恢复 map 文件。
