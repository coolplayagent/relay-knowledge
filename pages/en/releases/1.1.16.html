relay-knowledge 1.1.16 release notes

Version 1.1.16 makes the repository-owned CodeSpec and Knowledge maps a typed, agent-visible contract and strengthens the durable code-index and software-projection lifecycle. It also adds Angular and Vue framework graph extraction and refreshes the cross-platform release baseline.

Published August 30, 2026.

Release downloads crates.io Checksums

Install and verify

cargo install relay-knowledge --version 1.1.16 --locked
relay-knowledge version --format json
relay-knowledge map validate --type all --format json

Upgrade every writer and reader that shares a repository before migrating its visible Repository Map v3 contract. Back up or commit repository-owned map files before a migration, and use the documented service lifecycle dry-run before replacing a resident service binary.

Typed CodeSpec and Knowledge maps

Repository Map v3 uses the visible codespec/ and knowledge/ roots. The CLI now exposes the two map types through one validation, inspection, routing, and migration surface instead of requiring agents to infer repository structure from files.

  • map validate --type all validates both governed roots and reports diagnostics without rewriting them.
  • map show exposes typed directory scope, key files, load policy, update policy, and cross-map relationships.
  • map route resolves authored sources such as the repository business glossary.
  • The CLI skill includes Draft 2020-12 schemas for Knowledge Map, CodeSpec Map, and Business Glossary contracts.
  • Foundational self-iteration cases protect help discovery, validation, directory filtering, and business routing.

Framework and software graph coverage

The repository graph now extracts Angular and Vue framework evidence and keeps software projections tied to the same committed source scope as code facts. Missing external packages remain unresolved edge metadata rather than being reported as repository damage.

  • Framework queries expose components, routes, dependencies, and related graph edges with evidence.
  • Software projections publish through durable, lease-aware work instead of bypassing index ownership.
  • Freshness, active task, checkpoint, and publication state remain observable through repository status.
relay-knowledge repo framework <alias> \
  --framework angular --kind component \
  --ref <commit> --freshness wait-until-fresh --format json

relay-knowledge repo software <alias> \
  --kind relationships --ref <commit> \
  --freshness wait-until-fresh --format json

Durable indexing and architecture boundaries

  • Indexing orchestration is split into explicit start, session, worker, recovery, snapshot, projection, and publication responsibilities.
  • Repository work preserves durable task leases, bounded retries, checkpoints, single-writer ownership, and publication fences.
  • Clock, identity, runtime, storage, network, and service lifecycle ownership is enforced by stronger architecture checks.
  • Large software projections use lease-friendly bounded work so maintenance does not block query hot paths.

Release packages

The release contains six platform archives, checksums.txt, artifact attestations, and the versioned CLI skill archive. Linux GNU binaries are built and started on a glibc 2.28 baseline before publication.

  • Linux x64 and ARM64
  • macOS Intel and Apple Silicon
  • Windows x64 and ARM64
  • relay-knowledge-cli-skill-v1.1.16.tar.gz for agent CLI workflows
