relay-knowledge 1.1.18 release notes

Version 1.1.18 adds Maven reactor dependency evidence and downstream impact, improves code-call retrieval and index diagnostics, and strengthens Windows SQLite storage defaults and validation.

Release date: September 18, 2026.

Release downloads crates.io Checksums

Install and verify

cargo install relay-knowledge --version 1.1.18 --locked
relay-knowledge version --format json
relay-knowledge map validate --type all --format json
relay-knowledge service doctor --format json

Release archives contain six platform binaries. Verify the selected archive against checksums.txt before installing it. The CLI skill archive is distributed separately in the same GitHub Release.

What changed

  • Maven reactor modules and relationships are indexed as snapshot-scoped facts, with paginated dependency and downstream-impact views.
  • Configuration reads, cross-language type calls, Java class-member calls, and unresolved C function-pointer calls have more complete graph evidence.
  • Index diagnostics expose bounded previews, explicit truncation, content-integrity state, and source I/O failures without hiding stale or degraded scopes.
  • Cold indexing reduces configuration-scan work and temporary full-text-search parameter copies while retaining durable checkpoints and search documents.
  • New Windows installations use an account-SID SQLite data path with protected ACLs; existing LocalAppData stores remain selected during upgrade.

Upgrade and rollback

Software projection schema 9 makes existing Maven projections stale until a durable repair or reindex completes. Allow that work to finish before relying on reactor modules or downstream impact. Back up the runtime database and all shards before upgrade. Before downgrading, stop the service, drain or cancel active tasks, and restore a consistent pre-upgrade database backup. Do not edit reactor markers or checkpoints by hand.

On Windows, provision the account-SID directory under D:\relay-knowledge\users\<user-sid>\data for new installs, or set RELAY_KNOWLEDGE_DATA_DIR to an absolute writable directory. Existing data is not moved automatically. Run the service lifecycle dry-run and service doctor before replacing a resident binary. Repository Map v4 still requires a 1.1.17 or newer reader; restore map files from Git or backup before using an older reader.
